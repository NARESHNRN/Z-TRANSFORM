# Digital Control System Design Using Z-Transforms

An interactive React + TypeScript learning studio for undergraduate digital control systems.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite. The application has no backend: calculations, charts, and validation run in the browser.

## Production build

```bash
npm run build
npm run preview
```

## Included modules

- Digital control basics with a live sampling simulator
- Common-sequence Z-transform calculator
- Difference equation solver
- Digital control system designer with poles, zeros, stability, and step response
- Simulation lab, applications, and presentation-ready project notes

## Project structure

- `src/App.tsx` - routes, educational views, and interactive tools
- `src/math.ts` - browser-side calculation utilities
- `src/styles.css` - responsive engineering interface styling
